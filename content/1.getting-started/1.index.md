Osmi AI — это платформа разработки генеративного ИИ с открытым исходным кодом для создания ИИ-агентов и рабочих процессов LLM.

Предлагается комплексное решение, которое включает в себя:

* [x] Визуальный конструктор
* [x] Отслеживание и аналитика
* [x] Оценки
* [x] Человек в петле
* [x] API, CLI, SDK, встроенный чат-бот
* [x] Команды и рабочие пространства

Существует 3 основных визуальных конструктора, а именно:

* Помощник
* Чатфлоу
* Агентфлоу

## Помощник

Помощник — самый удобный для новичков способ создания ИИ-агента. Пользователи могут создать чат-помощника, который будет следовать инструкциям, использовать необходимые инструменты и извлекать знания из загруженных файлов  ([RAG](https://en.wikipedia.org/wiki/Retrieval-augmented_generation)) для ответа на запросы пользователей.

## Чатфлоу

Chatflow предназначен для создания одноагентных систем, чат-ботов и простых потоков обучения на уровне магистратуры (LLM). Он более гибок, чем Assistant. Пользователи могут использовать продвинутые методы, такие как Graph RAG, Reranker, Retriever и т. д.

## Агентфлоу

Agentflow — это надстройка Chatflow & Assistant. Он может использоваться для создания чат-помощника, одноагентных и многоагентных систем, а также для комплексной организации рабочих процессов. Подробнее об [Agentflow V2](https://docs.flowiseai.com/using-flowise/agentflowv2)
