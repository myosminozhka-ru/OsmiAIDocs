Используя публичный API , вы можете программно выполнять многие из тех же задач, что и через графический интерфейс. В этом разделе представлен OSMI REST API.

Основные разделы API:

- [Ассистенты](/api-reference/assistants) — работа с ассистентами.
- [Вложения](/api-reference/attachments) — управление вложениями.
- [Сообщение чата](/api-reference/chat-message) — работа с сообщениями в чате.
- [Агенты](/api-reference/chatflows) — управление агентами.
- [База документов](/api-reference/document-store) — работа с базой документов.
- [Обратная связь](/api-reference/feedback) — управление обратной связью.
- [Лиды](/api-reference/leads) — работа с лидами.
- [Пинг](/api-reference/ping) — проверка доступности API.
- [Прогнозирование](/api-reference/prediction) — выполнение прогноза.
- [Инструменты](/api-reference/tools) — управление инструментами (узлами).
- [Обновление или вставка истории](/api-reference/upsert-history) — история операций вставки/обновления.
- [Параметры](/api-reference/variables) — управление переменными.
- [БД векторов](/api-reference/vector-upsert) — вставка/обновление векторных данных.
