## Получить все хранилища документов

::field-group
  :::field{name="HTTP"}
  GET `/document-store/store`:br Возвращает список всех хранилищ документов
  :::

  :::field{required name="Авторизация" type="string"}
  bearerAuth `JWT-токен`
  :::
::

Коды ответов:

- 200 — успешно (массив объектов)
- 500 — внутренняя ошибка

## Добавить или обновить документ в хранилище документов

::field-group
  :::field{name="HTTP"}
  POST `/document-store/upsert/{id}`:br Добавить новый документ или обновить существующий в хранилище документов
  :::

  :::field{required name="Авторизация" type="string"}
  bearerAuth `JWT-токен`
  :::

  :::field{required name="Параметры пути" type="string"}
  `id` (string · uuid) — ID хранилища
  :::

  :::field{name="Тело (application/json):"}
  `docId` (string · uuid | nullable) — ID документа внутри хранилища (при передаче — переиспользуется конфигурация) :br`metadata` (object | nullable) — метаданные (напр. `{"foo":"bar"}`)
  `replaceExisting` (boolean | nullable) :br — заменить существующий загрузчик новыми чанками (не удаляет эмбеддинги из векторного хранилища) :br`createNewDocStore` (boolean | nullable) — создать новое хранилище :br`docStore` (object | nullable) — конфиг нового хранилища (если `createNewDocStore=true`) :br`loader` (object | nullable) — конфиг загрузчика :br`splitter` (object | nullable) — конфиг сплиттера :br`embedding` (object | nullable) — конфиг эмбеддингов :br`vectorStore` (object | nullable) — конфиг векторного хранилища :br`recordManager` (object | nullable) — конфиг record manager
  :::
::

Коды ответов:

- 200 — операция выполнена
- 400 — некорректное тело запроса
- 500 — внутренняя ошибка

```json [Пример ответа]
{
  "numAdded": 1,
  "numDeleted": 1,
  "numUpdated": 1,
  "numSkipped": 1,
  "addedDocs": [
    {
      "pageContent": "This is the content of the page.",
      "metadata": { "author": "John Doe", "date": "2024-08-24" }
    }
  ]
}
```

## Повторно обработать и добавить или обновить все документы в хранилище документов

::field-group
  :::field{name="HTTP"}
  POST `/document-store/refresh/{id}`:br Повторно обработать и добавить или обновить все существующие документы в хранилище документов
  :::

  :::field{required name="Авторизация" type="string"}
  bearerAuth `JWT-токен`
  :::

  :::field{required name="Параметры пути" type="string"}
  `id` (string · uuid) — ID хранилища
  :::

  :::field{name="Тело (application/json):"}
  `items` (object [] ) — массив конфигов для отдельных документов :br (`docId`, `metadata`, `loader`, `splitter`, `embedding`, `vectorStore`, `recordManager`, и т.д.)
  :::
::

Коды ответов:

- 200 — операция выполнена (массив результатов)
- 400 — некорректное тело запроса
- 500 — внутренняя ошибка

## Запрос на поиск в vector store

::field-group
  :::field{name="HTTP"}
  POST `/document-store/vectorstore/query`:br Запрос на поиск для вставленных (upserted) фрагментов
  :::

  :::field{required name="Авторизация" type="string"}
  bearerAuth `JWT-токен`
  :::

  :::field{name="Тело (application/json):"}
  `storeId` (string) — ID хранилища :br`query` (string) — текст запроса
  :::
::

Коды ответов:

- 200 — успешно (время выполнения и список найденных документов)
- 400 — некорректное тело запроса
- 500 — внутренняя ошибка

```json [Пример ответа]
{
  "timeTaken": 1,
  "docs": [
    {
      "pageContent": "This is the content of the page.",
      "metadata": { "author": "John Doe", "date": "2024-08-24" }
    }
  ]
}
```

## Создать новое хранилище документов

::field-group
  :::field{name="HTTP"}
  POST `/document-store/store`:br Создаёт хранилище документов с переданными параметрами.
  :::

  :::field{required name="Авторизация" type="string"}
  bearerAuth `JWT-токен`
  :::

  :::field{name="Тело (application/json):"}
  `id` (string · uuid) — уникальный ID хранилища :br`name` (string) — имя :br`description` (string) — описание :br`loaders` (string) — загрузчики (JSON-строка) :br`whereUsed` (string) — места использования (JSON-строка) :br`status` (string · enum) — статус: `EMPTY`|`SYNC`|`SYNCING`|`STALE`|`NEW`|`UPSERTING`|`UPSERTED`:br`vectorStoreConfig` (string) — конфиг векторного хранилища (JSON-строка) :br`embeddingConfig` (string) — конфиг эмбеддинга (JSON-строка) :br`recordManagerConfig` (string) — конфиг record manager (JSON-строка) :br`createdDate` (string · date-time) — дата создания :br`updatedDate` (string · date-time) — дата обновления
  :::
::

Коды ответов:

- 200 — успешно создано
- 400 — некорректное тело запроса
- 500 — внутренняя ошибка

## Обновить конкретный чанк

::field-group
  :::field{name="HTTP"}
  PUT `/document-store/chunks/{storeId}/{loaderId}/{chunkId}`:br Обновляет выбранный чанк у загрузчика документов.
  :::

  :::field{required name="Авторизация" type="string"}
  bearerAuth `JWT-токен`
  :::

  :::field{name="Параметры пути"}
  `storeId` (string) — ID хранилища :br`loaderId` (string) — ID загрузчика :br`chunkId` (string) — ID чанка
  :::

  :::field{name="Тело (application/json):"}
  `pageContent` (string) — содержимое
  `metadata` (object) — метаданные (напр. `{"author":"John Doe","date":"2024-08-24"}`)
  :::
::

Коды ответов:

- 200 — успешно (возвращает обновлённый список чанков и метаданные файла)
- 404 — хранилище не найдено
- 500 — внутренняя ошибка
