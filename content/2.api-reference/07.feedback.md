## Список всех фидбэков для агентов

::field-group
  :::field{name="HTTP"}
  GET `/feedback/{id}`
  Возвращает все фидбэки для указанного агента.
  :::

  :::field{required name="Авторизация" type="string"}
  bearerAuth `JWT-токен`
  :::

  :::field{required name="Параметры пути" type="string"}
  `id` (string) — агент ID
  :::

  :::field{name="Query-параметры (опционально):"}
  `chatId` (string) — фильтр по агент ID :br `sortOrder` (enum) — порядок сортировки фидбэков :br По умолчанию: `asc`:br Возможные значения: `asc`, `desc`:br`startDate` (string · date-time) — фильтр «начиная с даты» :br `endDate` (string · date-time) — фильтр «до даты»
  :::
::

Коды ответов:

- 200 — успешная операция (возвращается массив объектов)
- 500 — внутренняя ошибка сервера

```json [Пример ответа]
[
  {
    "id": "123e4567-e89b-12d3-a456-426614174000",
    "chatflowid": "123e4567-e89b-12d3-a456-426614174000",
    "chatId": "text",
    "messageId": "123e4567-e89b-12d3-a456-426614174000",
    "rating": "THUMBS_UP",
    "content": "text",
    "createdDate": "2025-09-12T00:03:12.350Z"
  }
]

```

## Создать фидбэк сообщения чата

::field-group
  :::field{name="HTTP"}
  GET `/feedback/`:br Создаёт новый фидбэк для конкретного агента.
  :::

  :::field{required name="Авторизация" type="string"}
  bearerAuth `JWT-токен`
  :::

  :::field{required name="Параметры пути" type="string"}
  `id` (string · uuid) — уникальный идентификатор фидбэка
  :::

  :::field{name="Query-параметры (опционально):"}
  `chatflowid` (string · uuid) — идентификатор агента :br `chatId` (string) — идентификатор чата :br `messageId` (string · uuid) — идентификатор сообщения :br `rating` (enum) — оценка сообщения :br `Возможные` значения: `THUMBS_UP`, `THUMBS_DOWN`:br`content` (string) — текст фидбэка :br `createdDate` (string · date-time) — дата и время создания
  :::
::

Коды ответов:

- 200 — фидбэк успешно создан
- 400 — некорректные входные данные
- 500 — внутренняя ошибка сервера

```json [Пример запроса]
{
  "id": "123e4567-e89b-12d3-a456-426614174000",
  "chatflowid": "123e4567-e89b-12d3-a456-426614174000",
  "chatId": "text",
  "messageId": "123e4567-e89b-12d3-a456-426614174000",
  "rating": "THUMBS_UP",
  "content": "text",
  "createdDate": "2025-09-12T00:03:12.350Z"
}
```

```json [Пример ответа]
{
    {
    "id": "123e4567-e89b-12d3-a456-426614174000",
    "chatflowid": "123e4567-e89b-12d3-a456-426614174000",
    "chatId": "text",
    "messageId": "123e4567-e89b-12d3-a456-426614174000",
    "rating": "THUMBS_UP",
    "content": "text",
    "createdDate": "2025-09-12T00:03:12.350Z"
    }
}
```

## Обновить фидбэк сообщения чата

::field-group
  :::field{name="HTTP"}
  PUT `/feedback/{id}`
  Обновляет существующий фидбэк
  :::

  :::field{required name="Авторизация" type="string"}
  bearerAuth `JWT-токен`
  :::

  :::field{required name="Параметры пути" type="string"}
  `id` (string) — Идентификатор отзыва
  :::

  :::field{name="Тело запроса (application/json):"}
  `id` (string · uuid) :br `chatflowid` (string · uuid) :br `chatId` (string) :br `messageId` (string · uuid) :br `rating` (enum: `THUMBS_UP`, `THUMBS_DOWN`) :br `content` (string) :br `createdDate` (string · date-time)
  :::
::

Коды ответов:

- 200 — фидбэк успешно обновлён
- 400 — некорректные входные данные
- 404 — фидбэк с указанным ID не найден
- 500 — внутренняя ошибка сервера

```json [Пример запроса]
{
  "id": "123e4567-e89b-12d3-a456-426614174000",
  "chatflowid": "123e4567-e89b-12d3-a456-426614174000",
  "chatId": "text",
  "messageId": "123e4567-e89b-12d3-a456-426614174000",
  "rating": "THUMBS_UP",
  "content": "text",
  "createdDate": "2025-09-12T00:03:12.350Z"
}
```

```json [Пример ответа]
{
  "id": "123e4567-e89b-12d3-a456-426614174000",
  "chatflowid": "123e4567-e89b-12d3-a456-426614174000",
  "chatId": "text",
  "messageId": "123e4567-e89b-12d3-a456-426614174000",
  "rating": "THUMBS_UP",
  "content": "text",
  "createdDate": "2025-09-12T00:03:12.350Z"
}

```
