OSMI предоставляет пошаговое отслеживание для **Agentflow V2**.

![](/assets/image%20\(332\).png)

Кроме того, OSMI интегрируется с несколькими аналитическими сервисами (поставщиками):

- [Langfuse](https://langfuse.com/)

## Настройка

1. В правом верхнем углу вашего Агента или Мульти агента нажмите «Настройки» → «Конфигурация».

![Screenshot of user clicking in the configuration menu](/assets/analytic-1.webp){width="375"}

2. Перейдите в раздел «Аналитика Агента».

![Screenshot of the Analyse Chatflow section with the different Analytics providers](/assets/analytic-2.png)

3. Вы увидите список поставщиков и соответствующие поля конфигурации.

![Screenshot of an analytics provider with credentials fields expanded](/assets/image%20\(82\).png)

4. Заполните данные для входа и другие параметры конфигурации, затем включите поставщика («ON»). Нажмите «Сохранить».

![Screenshot of analytics providers enabled](/assets/image%20\(83\).png)

## API

После включения аналитики через интерфейс пользователя вы можете переопределить или добавить дополнительные настройки в теле запроса Prediction API:

```json
{
  "question": "hi there",
  "overrideConfig": {
    "analytics": {
      "langFuse": {
        // langFuse
        "userId": "user1"
      }
    }
  }
}
```
