OSMI предоставляет пошаговое отслеживание для **Мульти агента V2**.

Кроме того, OSMI интегрируется с несколькими аналитическими сервисами (поставщиками):

- Langfuse

## Настройка

1. В правом верхнем углу вашего Агента или Мульти агента нажмите «Настройки» → «Конфигурация».
2. Перейдите в раздел «Аналитика агента».
3. Вы увидите список поставщиков и соответствующие поля конфигурации.
4. Заполните данные для входа и другие параметры конфигурации, затем включите поставщика («ON»). Нажмите «Сохранить».

## API

После включения аналитики через интерфейс пользователя вы можете переопределить или добавить дополнительные настройки в теле запроса Прогнозирование API:

```json
{
  "question": "hi there",
  "overrideConfig": {
    "analytics": {
      "langFuse": {
        // langFuse
        "userId": "user1"
      }
    }
  }
}
```
