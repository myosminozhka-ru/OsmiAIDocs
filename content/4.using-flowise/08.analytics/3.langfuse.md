**Langfuse** — это платформа с открытым исходным кодом для разработки больших языковых моделей (LLM), которая помогает командам отслеживать вызовы API, контролировать производительность и устранять проблемы в их AI-приложениях. Благодаря встроенной интеграции, вы можете использовать OSMI для быстрого создания сложных LLM-приложений без кода, а затем использовать Langfuse для их мониторинга и улучшения. Интеграция поддерживает все сценарии использования OSMI, включая: взаимодействие через пользовательский интерфейс, API и встроенные компоненты.

Вы можете при желании добавить релиз, чтобы отметить текущую версию потока. Обычно не нужно изменять другие параметры.
