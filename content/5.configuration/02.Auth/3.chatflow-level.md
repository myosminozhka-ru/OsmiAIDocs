После создания диалога агента, по умолчанию, ваш поток доступен для публичного доступа. Любой, у кого есть идентификатор агента, может запускать предсказания через Embed или API. Если вы хотите разрешить определённым лицам доступ и взаимодействие с этим потоком, вы можете это сделать, назначив для него API агента.

## API агента (**API Key**)

В панели управления перейдите в раздел «API агентов». Там должен быть создан ключ по умолчанию — DefaultKey. Также вы можете добавлять или удалять любые ключи.

## **Агенты**

Перейдите к выбранному агенту, и теперь вы можете выбрать API агента, который хотите использовать для защиты этого агента.

После назначения API агента доступ к API агенту возможен только при наличии заголовка Authorization с правильным API агентом, указанным в HTTP-запросе.

```json
"Authorization": "Bearer <your-api-key>"
```

Пример вызова API через **Postman**.
