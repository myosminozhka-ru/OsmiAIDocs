После создания диалога агента, по умолчанию, ваш поток доступен для публичного доступа. Любой, у кого есть идентификатор агента, может запускать предсказания через Embed или API. Если вы хотите разрешить определённым лицам доступ и взаимодействие с этим потоком, вы можете это сделать, назначив для него API-ключ.

## API-ключ (**API Key**)

В панели управления перейдите в раздел «API-ключи» (API Keys). Там должен быть создан ключ по умолчанию — DefaultKey. Также вы можете добавлять или удалять любые ключи.

## **Агенты**

Перейдите к выбранному агенту, и теперь вы можете выбрать API-ключ, который хотите использовать для защиты этого агента.

![](/assets/image%20\(3\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\).png)

После назначения API-ключа доступ к API агента возможен только при наличии заголовка Authorization с правильным API-ключом, указанным в HTTP-запросе.

```json
"Authorization": "Bearer <your-api-key>"
```

Пример вызова API через **Postman**.
