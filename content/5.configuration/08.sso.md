OSMI поддерживает протокол [OIDC](https://openid.net/), который позволяет пользователям входить в приложение через единый вход (SSO). В настоящее время настройку SSO может выполнить только [администратор]() организации.

## Microsoft

1. В портале Azure найдите «Microsoft Entra ID»:

![](/assets/image%20\(193\).png)

2. В левом меню выберите «Регистрация приложений» (App Registrations), затем «Создать регистрацию» (New Registration):

![](/assets/image%20\(194\).png)

3. Введите название приложения и выберите «Одноорганизационный» (Single Tenant):

![](/assets/image%20\(195\).png)

4. После создания приложения запишите IDs — Application (client) ID и Directory (tenant) ID:

![](/assets/image%20\(196\).png)

5. В левом меню выберите «Сертификаты и секреты» (Certificates & secrets) -> «Создать секрет клиента» (New client secret) -> «Добавить» (Add):

![](/assets/image%20\(198\).png)

6. После создания секрета скопируйте значение (Value), а не Secret ID:

![](/assets/image%20\(199\).png)

7. В левом меню выберите «Аутентификация» (Authentication) -> «Добавить платформу» (Add a platform) -> «Web»:

![](/assets/image%20\(201\).png)

8. Заполните Redirect URIs. Их нужно изменить в зависимости от вашей реализации: `http[s]://[your-osmi-instance.com]/api/v1/azure/callback`Убедитесь, что URI создан.

![](/assets/image%20\(218\).png){width="514"}

9. Вернитесь в приложение OSMI и войдите как Администратор организации. Перейдите в раздел настроек SSO в левом меню. Заполните Azure Tenant ID и Client ID из шага 4, а также Client Secret из шага 6. Нажмите «Проверить конфигурацию» (Test Configuration), чтобы проверить успешность соединения:

![](/assets/image%20\(219\).png)

10. Включите и сохраните настройку.Перед тем, как пользователи смогут входить через SSO, их необходимо пригласить. Следуйте руководству по приглашению пользователей для входа через SSO. Также приглашённые пользователи должны быть добавлены в раздел «Пользователи каталога» (Directory Users) Azure.

![](/assets/image%20\(220\).png){width="563"}

11. Наконец, активируйте и сохраните это:

![](/assets/image%20\(221\).png){width="563"}

12. Прежде чем пользователи смогут войти с помощью SSO, их необходимо сначала пригласить. Ознакомьтесь с инструкцией по отправке приглашений для входа через SSO для пошагового руководства. Также приглашённые пользователи должны быть частью раздела "[Пользователи каталога](/configuration/sso#inviting-users-for-sso-sign-in)" в Azure.

![](/assets/image%20\(2\)%20\(1\)%20\(2\).png)

## Google

Чтобы включить вход через Google на вашем сайте, сначала нужно настроить ID клиента API Google.

Для этого выполните следующие шаги:

1\. Откройте страницу «Учётные данные» (Credentials) в консоли API Google.

2\. Нажмите «Создать учётные данные» > «ID клиента OAuth» (Create credentials > OAuth client ID).

![](/assets/image%20\(224\).png){width="563"}

3\. Выберите «Веб-приложение» (Web Application).

![](/assets/image%20\(225\).png){width="504"}

4\. Заполните поля Redirect URIs. Их необходимо изменить в зависимости от вашей реализации: `http[s]://[your-osmi-instance.com]/api/v1/google/callback`:

![](/assets/image%20\(226\).png){width="563"}

5\. После создания сохраните Client ID и секрет (Secret).

![](/assets/image%20\(227\).png)

6\. В приложении OSMI внесите полученные Client ID и Secret. Проверьте соединение и сохраните настройки

![](/assets/image%20\(228\).png){width="563"}

## Auth0

1. Зарегистрируйтесь на платформе [Auth0]() и создайте новое приложение.

![](/assets/image%20\(229\).png)

2. Выберите «Обычное веб-приложение» (Regular Web Application).

![](/assets/image%20\(230\).png)

3. Настройте поля, такие как Название, Описание. Запишите Domain, Client ID и Client Secret.

![](/assets/image%20\(231\).png)

4\. Заполните URI для приложения, который нужно изменить в зависимости от вашей реализации: `http[s]://[your-osmi-instance.com]/api/v1/auth0/callback`:

![](/assets/image%20\(232\).png)

5. Во вкладке API убедитесь, что включена API управления Auth0 (Auth0 Management API) с разрешениями:- read\:users- read\:client\_grants

![](/assets/image%20\(233\).png)

6\. В приложении OSMI введите Domain, Client ID и Secret. Проверьте соединение и сохраните настройки.

![](/assets/image%20\(234\).png){width="563"}

## Приглашение пользователей для входа через SSO

Приглашение пользователей для входа через SSO Чтобы новый пользователь мог войти в систему, его необходимо пригласить в приложение osmi. Это важно для учета роли и рабочей области приглашенного пользователя. См. раздел «Приглашение пользователей» для настройки переменных окружения

После приглашения пользователь получит ссылку для входа:

![](/assets/image%20\(222\).png){width="449"}

Нажатие на кнопку перенаправит его прямо на страницу входа через SSO OSMI.

\#default
![](/assets/image%20\(210\).png){width="400"}

Или пользователь может перейти в приложение OSMI и выбрать вход через SSO.

\#default
![](/assets/image%20\(211\).png){width="437"}
