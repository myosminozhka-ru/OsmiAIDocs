OSMI-AI поддерживает протокол OIDC, который позволяет пользователям входить в приложение через единый вход (SSO). В настоящее время настройку SSO может выполнить только [администратор]() организации.

## Microsoft

1. В портале Azure найдите «Microsoft Entra ID»:

2. В левом меню выберите «Регистрация приложений», затем «Создать регистрацию»:

3. Введите название приложения и выберите «Одноорганизационный»:

4. После создания приложения запишите IDs — Application (client) ID и Directory (tenant) ID:

5. В левом меню выберите «Сертификаты и секреты» -> «Создать секрет клиента» -> «Добавить»:

6. После создания секрета скопируйте значение, а не Secret ID:

7. В левом меню выберите «Аутентификация» -> «Добавить платформу» -> Веб:

8. Заполните Redirect URIs. Их нужно изменить в зависимости от вашей реализации: `http[s]://[your-osmi-ai-instance.com]/api/v1/azure/callback` Убедитесь, что URI создан.

9. Вернитесь в приложение osmi-ai и войдите как Администратор организации. Перейдите в раздел настроек SSO в левом меню. Заполните Azure Tenant ID и Client ID из шага 4, а также Client Secret из шага 6. Нажмите «Проверить конфигурацию», чтобы проверить успешность соединения:

10. Включите и сохраните настройку.Перед тем, как пользователи смогут входить через SSO, их необходимо пригласить. Следуйте руководству по приглашению пользователей для входа через SSO. Также приглашённые пользователи должны быть добавлены в раздел «Пользователи каталога» Azure.

11. Наконец, активируйте и сохраните это:

12. Прежде чем пользователи смогут войти с помощью SSO, их необходимо сначала пригласить. Ознакомьтесь с инструкцией по отправке приглашений для входа через SSO для пошагового руководства. Также приглашённые пользователи должны быть частью раздела "[Пользователи каталога](/configuration/sso#inviting-users-for-sso-sign-in)" в Azure.

## Google

Чтобы включить вход через Google на вашем сайте, сначала нужно настроить ID клиента API Google.

Для этого выполните следующие шаги:

1\. Откройте страницу «Учётные данные»в консоли API Google.

2\. Нажмите «Создать учётные данные» > «ID клиента OAuth».

3\. Выберите «Веб-приложение».

4\. Заполните поля Redirect URIs. Их необходимо изменить в зависимости от вашей реализации: `http[s]://[your-osmi-ai-instance.com]/api/v1/google/callback`:

5\. После создания сохраните Client ID и секрет (Secret).

6\. В приложении osmi-ai внесите полученные Client ID и Secret. Проверьте соединение и сохраните настройки

## Auth0

1. Зарегистрируйтесь на платформе Auth0 и создайте новое приложение.

2. Выберите «Обычное веб-приложение».

3. Настройте поля, такие как Название, Описание. Запишите Domain, Client ID и Client Secret.

4. Заполните URI для приложения, который нужно изменить в зависимости от вашей реализации: `http[s]://[your-osmi-ai-instance.com]/api/v1/auth0/callback`:

5. Во вкладке API убедитесь, что включена API управления Auth0 (Auth0 Management API) с разрешениями:- read\:users- read\:client\_grants

6. В приложении osmi-ai введите Domain, Client ID и Secret. Проверьте соединение и сохраните настройки.

## Приглашение пользователей для входа через SSO

Приглашение пользователей для входа через SSO Чтобы новый пользователь мог войти в систему, его необходимо пригласить в приложение osmi-ai. Это важно для учета роли и рабочей области приглашенного пользователя. См. раздел «Приглашение пользователей» для настройки переменных окружения

После приглашения пользователь получит ссылку для входа:

Нажатие на кнопку перенаправит его прямо на страницу входа через SSO osmi-ai.

\#default

Или пользователь может перейти в приложение osmi-ai и выбрать вход через SSO.
