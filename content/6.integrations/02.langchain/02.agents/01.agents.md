Сам по себе языковая модель не может выполнять действия — она только генерирует текст.

Агенты — это системы, которые используют LLM в качестве движка для рассуждений, чтобы определить, какие действия необходимо выполнить, и какие входные данные для этих действий нужны. Результаты этих действий могут возвращаться обратно агенту, который решит, нужны ли дополнительные действия или можно завершить работу.
