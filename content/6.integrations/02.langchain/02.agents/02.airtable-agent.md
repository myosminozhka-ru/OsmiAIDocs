## Функциональность Airtable Agent

Airtable Agent предназначен для облегчения взаимодействия между OSMI AI и таблицами Airtable, позволяя пользователям задавать запросы к данным Airtable в разговорной форме. Используя этого агента, пользователи могут задавать вопросы о содержимом своей базы Airtable и получать релевантные ответы на основе сохранённых данных. Это особенно полезно для быстрого извлечения конкретной информации, автоматизации рабочих процессов или составления сводок по данным в Airtable.

Например, Airtable Agent можно использовать для ответов на вопросы вроде:

- «Сколько задач осталось незаконченных в моей таблице отслеживания проектов?»
- «Каковы контактные данные клиентов, занесённых в CRM?»
- «Дайте мне краткое содержание всех записей, добавленных за прошедшую неделю.»

Эта функция помогает пользователям получать аналитическую информацию из своих баз Airtable без необходимости вручную навигировать по интерфейсу Airtable, делая управление и анализ данных более удобным и интерактивным.

### Вводные данные

Агент Airtable требует следующие входные параметры для эффективной работы:

- Языковая модель: Модель языка, которая будет использоваться для обработки запросов. Этот параметр обязательный и влияет на качество и точность ответов, которые предоставляет агент.
- Модерация контента: Необязательный параметр, который включает функцию модерирования контента. Помогает обеспечить, чтобы запросы были подходящими и не содержали оскорбительного или вредоносного содержимого.
- Учетные данные для подключения: Обязательный параметр для подключения к Airtable. Пользователи должны выбрать соответствующие учетные данные с правами доступа к их данным Airtable.
- ID базы данных (Base ID): Идентификатор базы Airtable, к которой нужно подключиться. Обязательное поле, его можно найти в документации API Airtable или в настройках базы. Например, в URL `https://airtable.com/app11RobdGoX0YNsC/tblJdmvbrgizbYlCO/viw9UrP77idOCE4ee`, часть `app11RobdGoX0YNsC` — это Base ID. Он указывается, чтобы указать, какая база содержит нужные данные.
- ID таблицы (Table ID): Идентификатор конкретной таблицы внутри базы Airtable. Также обязательное поле, помогает агенту определить, с какой таблицей работать. В примере URL `https://airtable.com/app11RobdGoX0YNsC/tblJdmvbrgizbYlCO/viw9UrP77idOCE4ee`[](https://airtable.com/app11RobdGoX0YNsC/tblJdmvbrgizbYlCO/viw9UrP77idOCE4ee), часть `tblJdmvbrgizbYlCO` — это Table ID.
- Дополнительные параметры: Необязательные параметры, которые можно использовать для настройки работы агента. Их можно конфигурировать в зависимости от конкретных сценариев использования.
- Return All: Этот параметр позволяет вернуть все записи из указанной таблицы. Если включен, будут получены все записи, иначе — только определенное число.
- Limit: Задает максимальное количество записей для возврата, если параметр Return All отключен. Значение по умолчанию — `100`.
