## Определения

Цепочка вопросов и ответов, основанная на поиске, которая интегрируется с компонентом поиска и позволяет настраивать входные параметры для выполнения задач по вопросам и ответам.

**Чат-боты на основе поиска:** Чат-боты, использующие поиск, генерируют ответы, выбрав предварительно заданные ответы из базы данных или набора возможных ответов. Они "извлекают" наиболее подходящий ответ на основе ввода пользователя.

**QA (Вопрос-Ответ):** Системы QA предназначены для ответа на вопросы, заданные на естественном языке. Обычно они включают понимание вопроса и поиск или генерацию подходящего ответа.

## Входные данные

- Модель языка
- Поисковая система на основе векторных представлений
- Память (опционально)

## Параметры

| Название           | Описание                                                                   | Return Source Documents | System Message                                                  | Chain Option       |
| ------------------ | -------------------------------------------------------------------------- | ----------------------- | --------------------------------------------------------------- | ------------------ |
| Summarization      | Метод, который суммирует длинный текст, выделяя ключевые идеи.             | Да/Нет                  | "Пожалуйста, предоставьте краткое резюме основного содержания." | Summarization      |
| Question Answering | Обработка запросов, ответ на вопросы на основе документов или базы знаний. | Да/Нет                  | "Ответьте на вопрос, основываясь на предоставленных данных."    | Question Answering |
| Extractive QA      | Извлечение конкретных ответов из текста документов.                        | Да/Нет                  | "Пожалуйста, найдите и выделите точный ответ из текста."        | Extractive QA      |
| Chat               | Общий диалог и коммуникация, без специфического извлечения информации.     | Да/Нет                  | "Помогите с вашим запросом."                                    | Chat               |
| Custom Chain       | Пользовательский метод обработки данных с определенными правилами.         | Да/Нет                  | "Обработка по специальным инструкциям."                         | Custom Chain       |
