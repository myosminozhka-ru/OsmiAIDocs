## Определения

Цепочка вопросов и ответов, основанная на поиске, которая интегрируется с компонентом поиска Vectara и позволяет настраивать входные параметры для выполнения задач по вопросам и ответам.

## Входные данные

- [Хранилище Vectara (Vectara Store)](../vector-stores/vectara)

## Параметры

| Название               | Описание                                                                |
| ---------------------- | ----------------------------------------------------------------------- |
| Summarizer Prompt Name | Название модели или шаблона для генерации резюме                        |
| Response Language      | Желаемый язык для ответа                                                |
| Max Summarized Results | Максимальное число лучших результатов для суммирования (по умолчанию 7) |

## Выходные данные

| Название       | Описание                          |
| -------------- | --------------------------------- |
| VectaraQAChain | Конечный узел, возвращающий ответ |
