## Настройка LocalAI

[**LocalAI** ](https://github.com/go-skynet/LocalAI)это универсальный REST API, совместимый с спецификациями OpenAI API для локальных вычислений. Он позволяет запускать большие языковые модели (и не только их) локально или на собственных серверах с потребительским оборудованием, поддерживая несколько семейств моделей, совместимых с форматом ggml.

Чтобы использовать ChatLocalAI в OSMI, выполните следующие шаги:

1. Клонируйте репозиторий

```text
git clone https://github.com/go-skynet/LocalAI
```

2. Перейдите в папку

```text
cd LocalAI
```

3. Скопируйте ваши модели в папку models/

```text
cp your-model.bin models/
```

Например:

Загрузите одну из моделей с сайта [gpt4all.io](https://gpt4all.io/index.html)

### Cкачайте gpt4all-j в папку models/

```text
wget https://gpt4all.io/models/ggml-gpt4all-j.bin -O models/ggml-gpt4all-j
```

В папке /models должна появиться скачанная модель.

![](</assets/image (22) (1) (1).png>)

4. Обратитесь к списку поддерживаемых моделей [здесь] .

```text
docker compose up -d --pull always
```

5. Теперь API доступен по адресу <http://localhost:8080>.

```text
curl http://localhost:8080/v1/models
```

# Ожидаемый ответ:

```text
# {"object":"list","data": [{"id":"ggml-gpt4all-j.bin","object":"model"}] }
```

Настройка в OSMI:
Перетащите компонент ChatLocalAI на рабочую область.

![](</assets/image (39).png>)

Заполните поля:
Base Path: базовый URL LocalAI, например <http://localhost:8080/v1> Model Name: имя модели, которую хотите использовать. Она должна быть в папке /models. Например: ggml-gpt4all-j.bin

Если вы запускаете OSMI и LocalAI через Docker на одной машине, возможно, потребуется изменить базовый путь на <http://host.docker.internal:8080/v1>.
Для систем на базе Linux используйте стандартный шлюз Docker: <http://172.17.0.1:8080/v1>.
