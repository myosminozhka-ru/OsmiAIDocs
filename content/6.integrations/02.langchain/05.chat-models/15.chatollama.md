## Требования

1. Скачайте [Ollama](https://github.com/ollama/ollama) или запустите его через [Docker.](https://hub.docker.com/r/ollama/ollama)
2. Пример команды для запуска Docker-экземпляра с llama3:
   ```bash
   docker run -d -v ollama:/root/.ollama -p 11434:11434 --name ollama ollama/ollama
   docker exec -it ollama ollama run llama3
   ```

## Настройка

1. В разделе Chat Models перетащите узел ChatOllama на рабочую область.

![](/assets/image%20\(139\).png){width="563"}

2. Заполните модель, которая запущена у Ollama. Например: `llama2`. Также вы можете использовать дополнительные параметры.

![](/assets/image%20\(140\).png)

3. Теперь вы можете использовать узел ChatOllama в OSMI.

![](/assets/image%20\(141\).png)

### Дополнительно

Если вы запускаете и OSMI, и Ollama через Docker на одной машине, нужно изменить базовый URL для ChatOllama.

Для Windows и macOS укажите: http://host.docker.internal:8000.
Для систем на базе Linux используйте стандартный шлюз Docker, так как host.docker.internal недоступен: http://172.17.0.1:8000.

![](/assets/image%20\(142\).png){width="292"}
