## **Предварительные требования**

1. Аккаунт [OpenAI](https://openai.com/)
2. Создайте [API key](https://platform.openai.com/api-keys)

1. Модели чата > перетащите узел ChatOpenAI

![](/assets/image%20\(10\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\).png){width="563"}

2. Подключить учетные данные > нажмите «Создать новый»

![](/assets/image_openAI%20\(1\).png){width="278"}

2. Заполните учетные данные ChatOpenAI

![](/assets/image%20\(2\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\).png){width="563"}

4. Теперь вы можете использовать узел ChatOpenAI в OSMI

## Настройка пользовательского базового URL и заголовков

OSMI поддерживает использование пользовательского базового URL и заголовков для Chat OpenAI. Пользователи легко могут интегрировать сервисы, такие как OpenRouter, TogetherAI и другие, совместимые с API OpenAI.

### Вместе с AI (TogetherAI)

1. Обратитесь к официальной [документации](https://docs.together.ai/docs/openai-api-compatibility#nodejs) TogetherAI.
2. Создайте новую учетную запись, используя API-ключ TogetherAI.
3. В узле ChatOpenAI выберите Дополнительные параметры.
4. Измените Базовый путь (Base Path).

![](/assets/image%20\(4\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(2\).png){width="563"}

### Open Router

1. Обратитесь к официальной [документации](https://openrouter.ai/docs#quick-start) OpenRouter.
2. Создайте новую учетную запись, используя API-ключ OpenRouter.
3. В узле ChatOpenAI выберите Дополнительные параметры.
4. Измените Базовый путь (Base Path) и Базовые параметры (Base Options).

![](/assets/image%20\(5\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\).png){width="563"}

## Пользовательская модель (Custom Model)

Для моделей, которые не поддерживаются в стандартном узле ChatOpenAI, можно использовать опцию ChatOpenAI Custom. Это позволяет указать название модели вручную, например: `mistralai/Mixtral-8x7B-Instruct-v0.1`.

![](/assets/image%20\(84\).png)

## Загрузка изображений

Можно разрешить загрузку и анализ изображений с помощью LLM. Под капотом OSMI использует модель [OpenAI Vison ](https://platform.openai.com/docs/guides/vision)для обработки изображений.

![](/assets/image%20\(3\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(1\)%20\(2\).png){width="332"}

Работает только с цепочками: LLMChain, Conversation Chain, ReAct Agent и Conversational Agent.
Теперь в интерфейсе чата появится новая кнопка для загрузки изображений.
