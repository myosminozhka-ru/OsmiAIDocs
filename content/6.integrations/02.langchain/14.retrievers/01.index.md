# Ретриверы

---

Узлы Ретривер возвращают документы по необработанному запросу. Они более универсальны, чем БД вектора. Ретриверы не обязательно должен уметь хранить документы — ему достаточно только извлекать (или находить) их.

- [HyDE Retriever](hyde-retriever)
- [LLM Filter Retriever](llm-filter-retriever)
- [Multi Query Retriever](multi-query-retriever)
- [Prompt Retriever](prompt-retriever)
- [Reciprocal Rank Fusion Retriever](reciprocal-rank-fusion-retriever)
- [Similarity Score Threshold Retriever](similarity-score-threshold-retriever)
- [Vector Store Retriever](vector-store-retriever)
