# Code Interpreter by E2B

[E2B](https://e2b.dev/) — это бесплатная (open-source) среда выполнения (рантайм), предназначенная для выполнения кода, созданного искусственным интеллектом, в защищённых облачных песочницах. Например, когда пользователь просит сгенерировать столбчатую диаграмму по данным, модель (LLM) выдаст необходимый код на Python для построения этой диаграммы. Этот сгенерированный код отправляется в E2B, и результат выполнения содержит изображения диаграммы, исходный код, текст и т. д. Эти результаты отправляются обратно в LLM для финальной обработки перед отображением в чате.
