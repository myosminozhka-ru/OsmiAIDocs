# Elastic

## Предварительные условия

1. Вы можете начать с использования официального Docker image или воспользоваться облачным сервисом Elastic Cloud, официальной облачной платформой Elastic. В этой инструкции мы будем использовать облачную версию.
2. Зарегистрируйтесь на Elastic Cloud или войдите в существующий аккаунт.
3. Нажмите **Создать развертывание**. Затем укажите название развертывания и выберите провайдера.
4. После завершения развертывания вы увидите руководства по настройке, как показано ниже. Нажмите **Настроить векторный поиск**.
5. Теперь откроется страница Начало работы по векторному поиску.
6. В боковой панели слева нажмите **Индексы**. Затем — **Создать новый индекс**.
7. Выберите метод загрузки данных — Метод приема API.
8. Укажите название вашего поискового индекса и нажмите **Создать индекс**.
9. После создания индекса сгенерируйте новый API агент, запомните оба: и API агент, и URL.

## Настройка OSMI-AI

1. Добавьте новый узел **Elasticsearch** на холст и укажите имя индекса.
2. Добавьте новые учетные данные через **Elasticsearch API**.
3. Возьмите URL и API агент из ElasticSearch и заполните соответствующие поля.
4. После успешного создания учетных данных можно начинать загрузку (upsert) данных.
5. После успешной загрузки данных вы можете проверить их через панель управления Elastic.
6. Теперь вы можете задавать вопросы в чате.
