# Qdrant

## Предварительные условия

Локально запущенная инстанция Qdrant или инстанция Qdrant в облаке.

Получение инстанции Qdrant в облаке:

1. Перейдите в раздел Кластеров на панели управления Cloud Dashboard.
2. Выберите **Кластеры** и нажмите **+ Создать**.

![](/assets/qdrant/2.png)

3. Выберите конфигурации кластера и регион.
4. Нажмите **Создать**, чтобы запустить кластер.

## Настройка

1. Получите или создайте API агент в разделе Контроль доступа к данным на панели Cloud Dashboard.
2. Добавьте новый узел Qdrant на холст.
3. Создайте новые учетные данные для Qdrant, используя API агент.
4. Заполните необходимые поля в узле **Qdrant**:
   - URL сервера Qdrant.
   - Название коллекции.
5. Документы можно подключить к любому узлу категории [**Загрузчик документов**](../document-loaders/).
6. Векторные представления (Вложения) можно подключить к любому узлу категории [**Вложения**](../%D0%92%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F/).

## Фильтрация

Допустим, у вас есть несколько документов, добавленных (upserted), каждые с уникальным значением в метаданных по ключу `{source}`.

Вы хотите фильтровать по этому ключу. Qdrant поддерживает следующий синтаксис для фильтрации:

**UI** — через интерфейс пользователя (в случае визуальных инструментов).

**API** — через API-запрос

```json
"overrideConfig": {
    "qdrantFilter": {
        "should": [
            {
                "key": "metadata.source",
                "match": {
                    "value": "apple"
                }
            }
        ]
    }
}
```
